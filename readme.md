# AI Based Career Path Recommendation System

## Overview

This project is a web based career recommendation system that helps students find suitable career paths based on their academic branch, skills, interests, and preferred domain.

## Features

* Career recommendations based on skills and interests
* Career match percentage
* Career details and required skills
* Salary range and career growth information
* Sample job opportunities
* Personalized interview questions
* Trending career information
* Skills quiz

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
